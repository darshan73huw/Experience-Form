# LinkedIn Experience Form

A React app for adding, editing, and removing professional experience entries.

## Run locally

```sh
npm install
npm run dev
```

## Source structure

```text
src/
  components/       Profile header, experience form, experience list, and icons
  data/             Initial experience data and form defaults
  styles/           Global and app-specific styles
  utils/            Shared formatting helpers
  App.jsx           App state and component composition
  main.jsx          React entry point
```
